<h2>WARNING!</h2>
<p>Some Distros work differently for PyQt6</p>
<p>To resolve this issue run this command!</p>

# Fedora
```
sudo dnf install python3-pyqt6
```
# Ubuntu/Debian
```
sudo apt install python3-pyqt6
```
# Arch
```
sudo pacman -S python-pyqt6
```
